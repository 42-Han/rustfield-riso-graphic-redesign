# External Reference Routing

The folder `reference_images/` contains 23 active external-source references named `ref-###`. Numeric gaps indicate retired low-fit references. They sit beside the `board-###` user-board references in the same physical folder, but remain routed here as a separate functional subset. Product photos, contact sheets, brush-dominant works, text-heavy pages, and weak-fit candidates are not part of the active Skill.

Use these images to route observable visual mechanisms by function. Do not ask a generator to imitate one living artist, copy a signature character, or reproduce an exact composition.

## Human-figure safeguard

For a person-led source image:

1. The content source controls skin tone, hair, age band, clothing blocks, body type, pose/action, crop, and emotional energy.
2. Select at least one shape reference that actually contains a human figure or human gesture. Do not use an animal, food, or abstract collage as the primary figure-shape reference.
3. Use `ref-001`-`ref-004` or `ref-025` for scene hierarchy and printed figure/object coexistence. When no active reference matches the source person's body/gesture subtype, let the content source control figure construction rather than attaching a painterly or mismatched person.
4. Use `ref-007` only when a person-to-plant/tool relationship is part of the source identity.
5. Use `ref-008`-`ref-014` for animals and groups of animals; use `ref-015`-`ref-024` for composition, module rhythm, or print layering only. Palette authority remains one exact `board-###` image.
6. If the candidate changes the source person's silhouette, body type, skin tone, hair mass, pose energy, or clothing identity, reject it before surface review.

## Reference-role rule

Every attached image must have exactly one declared role: `composition`, `shape`, `palette`, `material`, or `typography`. A reference may not contribute new subjects or replace source identity. `palette` means ink families, dominance order, area proportions, and contrast only; `material` means print behavior only. Use the minimum attached set that resolves the design, and keep all supporting attachments within the Skill-wide reference limit.

Apply `material-language.md` before attachment. Relationship references are relationship evidence and animal references are animal-shape evidence, not material evidence. Printed-scene references support clean printed color masses; modular references support composition and print-layer behavior. Select only the active neutral reference files as generator inputs.

## Use boundary

Use the retained images only as internal reference material. Do not redistribute them as an asset pack, invoke creator names, or copy a signature character, exact composition, campaign, logo, or title treatment.
