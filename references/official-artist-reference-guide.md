# Official Artist Reference Set

The folder `ref_artists_official_2026-08-04/` contains 37 active images downloaded from official artist portfolios or their official Behance portfolios. It extends the broader Pinterest board with traceable, role-specific evidence. Brush-dominant and mixed-media candidates are not part of the active Skill.

Use these images to study observable mechanisms across several practitioners. Do not ask a generator to imitate one living artist, copy a signature character, or reproduce an exact composition.

## Human-figure safeguard

For a person-led source image:

1. The content source controls skin tone, hair, age band, clothing blocks, body type, pose/action, crop, and emotional energy.
2. Select at least one shape reference that actually contains a human figure or human gesture. Do not use an animal, food, or abstract collage as the primary figure-shape reference.
3. Use Asahi Nagata for scene hierarchy and printed figure/object coexistence. When no active reference matches the source person's body/gesture subtype, let the content source control figure construction rather than attaching a painterly or mismatched person.
4. Use Paca Kim only when a person-to-food/object/plant relationship is part of the source identity.
5. Use Min Pin for animals and groups of animals; use Atelier Bingo for composition, palette, module rhythm, or print layering only.
6. If the candidate changes the source person's silhouette, body type, skin tone, hair mass, pose energy, or clothing identity, reject it before surface review.

## Reference-role rule

Every attached image must have exactly one declared role: `composition`, `shape`, `material`, or `typography`. A reference may not contribute new subjects or replace source identity. Prefer two or more independent references when defining a branch.

Apply `material-language.md` before attachment. Paca Kim is relationship evidence and Min Pin is animal-shape evidence, not material evidence. Use Asahi Nagata for clean printed color masses and Atelier Bingo for modular composition, saturated palette, and print-layer behavior. Never select `_contact_sheets/` as generator inputs.
