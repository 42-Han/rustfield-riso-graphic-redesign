# Rustfield RISO Graphic Redesign

将照片、图像或文字主题重构为具有编辑感的几何 RISO / 丝网印刷图像。它保留原始主题的身份、关系与气氛，但会重新组织构图，而不是给原图叠加滤镜。

## 适用场景

- 单张或多张照片的风格化重绘
- 电影、游戏、书籍、活动、产品或地点的主题视觉
- 海报、社交媒体图像与图形化叙事画面

## 核心效果

- 先提炼身份、动作、关系和空间，再把对象压缩为清晰的主体色块与诊断形态。
- 每次都重新设计视觉锚点、对位元素和留白；除非用户明确要求，否则不沿用原图构图。
- 每张图选用一张项目参考图作为唯一配色依据，保持清晰、可辨的颜色关系。
- 使用中性自然白纸底、清晰硬边、低频不规则边缘、非等宽留缝、轻微套印错位和局部半调油墨感。
- 保留 RISO 的印刷物理感，但不做满屏噪点、模糊边缘或单纯的颗粒滤镜。

## 输入与输出

### 图生图

提供一张或多张图片。每张输入默认独立重构并各输出一张完整图像；只有明确要求时才会合成多张输入。

### 文生图

只提供文字主题时，Skill 会先提取具体的视觉锚点；对于电影、游戏、书籍等既有主题，会先确认其可识别的角色、场景、比例、关系或空间语法，再进行重构。

### 标题

如果用户没有预先说明，每张图只询问一次标题需求：

- 不加标题
- 自动生成标题
- 自定义标题

“海报”默认需要标题。输入图中必须保留的文字会自动保留，不会被误当成标题选项。

## 调用示例

```text
使用 $rustfield-riso-graphic-redesign 重绘这张照片。
```

```text
使用 $rustfield-riso-graphic-redesign 生成一张关于《海上钢琴师》的海报。
```

```text
使用 $rustfield-riso-graphic-redesign 重绘这四张图；不要标题。
```

## 工作顺序

`身份 → 形态概括 → 新构图 → 配色与信息 → 印刷表面`

每次生成会先确定视觉锚点、主体的概括形态、构图关系和配色，再一次性生成最终画面。失败时从原始输入重新生成，不做后期叠加修补。

## 许可与参考

本仓库中的参考图用于 Skill 的内部视觉校准。生成时应提取其可观察的配色、构图、字体或印刷特征，而不是复制具体作品、人物或文案。
